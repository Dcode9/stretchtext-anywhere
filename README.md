# Stretchtext Anywhere

A browser extension that turns any web page into [stretchtext](https://en.wikipedia.org/wiki/StretchText): click a sentence to grow an elaboration right where it stands, click again to shrink it back. Expansions are generated by a Pollinations text model and paid with **your own Pollen** (BYOP device-flow sign-in).

Built for [Pollinations quest #17998](https://github.com/pollinations/pollinations/issues/17998).

## How it works

- Enable the extension per site from the toolbar popup. Nothing touches a page until you turn it on there.
- Paragraphs on enabled pages split into clickable sentences (dotted underline).
- Click a sentence: the extension asks Pollinations for a one-or-two-sentence elaboration in the original author's voice and inserts it inline, tinted and slightly smaller.
- Click an expanded sentence again and it shrinks away. Expansions can themselves be stretched, up to the depth you set (default 3).
- Repeated expansions are cached for the session, so re-reading costs nothing.

## Sign-in (Bring Your Own Pollen)

The popup starts the OAuth **device flow**: it opens `enter.pollinations.ai/device`, you approve with a code, and the extension receives a user-scoped key. Expansions bill against your Pollen balance at the model's listed rate; keys appear in your dashboard and can be revoked anytime.

## Development

Plain Manifest V3, no build step. Load unpacked from `chrome://extensions` in developer mode.

- `background.js` — device-flow auth, per-site content-script registration, Pollinations chat call
- `content.js` / `content.css` — the stretchtext engine
- `popup/` — sign-in, per-site toggle, model and depth settings
